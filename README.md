# academia-industry-portal

A modern, responsive landing page for an Academia–Industry collaboration portal focused on skill mapping, internships, and placements.

## Features

- Hero section and call-to-action
- Skill mapping overview
- Internship marketplace cards
- Placement lifecycle timeline
- Responsive layout for desktop and mobile

## Run locally

1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Open the local URL shown in the terminal (typically http://localhost:5173)

## Build for production

npm run build

## Project structure

- `index.html` – page structure
- `src/main.js` – light interaction logic
- `src/styles.css` – all styling and layout
